DronePlus+ 3.0 — iPhone / GitHub Pages

1. Створіть резервну копію даних старого застосунку у розділі «Звіти».
2. Розпакуйте цей ZIP.
3. Завантажте до кореня репозиторію DronePlus усі файли, насамперед index.html та apple-touch-icon.png.
4. Залиште GitHub Pages: main / (root).
5. Відкрийте https://alex3semenenkov-svg.github.io/DronePlus/ у Safari, перевірте застосунок, додайте «На екран Домівки».

ДАНІ: localStorage з ключем dronplus_store_v1, старі дані не видаляються. Резервний відсоток 27% не є ставкою податку ФОП. Для продажів після оновлення ставка резерву зберігається у кожному рядку продажу, і звіт обчислює резерв окремо. Старі продажі без збереженої ставки мають резерв 0.

ВАЖЛИВО: для іконки на домашньому екрані необхідний файл apple-touch-icon.png, який слід завантажити поряд із index.html. Якщо іконка не оновилась, видаліть лише ярлик із домашнього екрана і додайте знову; не очищайте дані сайту.
